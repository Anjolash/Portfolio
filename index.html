Java, Spring Boot, React, TypeScript, Azure, Chrome Extension

A full-stack job application tracker built to replace spreadsheet-tracking during my own job search. Implements multi-provider OAuth (Microsoft Entra ID and Google) with per-user data isolation across the web app, browser extension, and REST API.
